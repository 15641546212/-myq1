第 1 轮 漏了需求
圆点只能看，不能点

提示词里只写了"圆点分页器"。AI 理解为"把圆点画出来"，于是只给了 el，没给 clickable。结果：圆点显示出来了，但点击没反应。

点第 3 个圆点 → 当前索引 2，没有跳转
pagination: {
  el: '.myqPagBad'
  // ❌ 漏了 clickable: true
}
第 2 轮 补齐需求
圆点是遥控器，不是装饰

第二轮把需求改写成"圆点必须能点击直接跳转，不能只是能看"。同一个 AI，立刻补上了 clickable: true。结果：点击圆点可以切换幻灯片。

点第 3 个圆点 → 当前索引 0，已跳转
pagination: {
  el: '.myqPagGood',
  clickable: true  // ✅ 补齐需求
}

把中文需求翻译成参数

答辩时最容易被追问的是"这句话对应哪个参数"。这张表就是交卷前该背下来的东西。

老师的要求 对应参数 为什么
无缝循环 loop: true 最后一张滑到第一张，无缝衔接，不会停在末尾
3.2 秒自动翻页，手动操作后不停 autoplay: { delay: 3200, disableOnInteraction: false } delay 单位毫秒；默认 disableOnInteraction 为 true（手动操作后停止），设为 false 才不会停
圆点分页器可点击 pagination: { el: '.myqPag', clickable: true } el 只负责"画"圆点；clickable: true 才让圆点变成可点击的遥控器
初始效果为 cube effect: 'cube' Swiper 内置 6 种 effect：slide / fade / cube / coverflow / flip / cards
