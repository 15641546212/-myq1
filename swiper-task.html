第 1 轮 漏了需求

圆点只能看，不能点

第 2 轮 补齐需求

圆点是遥控器，不是装饰

点第 3 个圆点 → 已跳转到第 3 张（圆点可点击）

八种效果随心换effect 参数 + slidesPerView 多图 + 进阶：按钮实时切换

改一个 effect 参数，轮播立刻换一种"性格"：slide / fade / cube / coverflow / flip / cards / creative；第 8 个按钮则演示 mousewheel 滚轮切换（参考官方 demo 100-space-between，多图并排 + 空格 + 滚轮翻页）。上面的 8 个按钮已经绑好了点击事件（读取 btn.dataset.fx），JS 还需要你补两段。

✍️ 任务 4 要求

基础分：初始化 #wySw4，实现循环 + 自动播放（3.2 秒）+ 圆点分页器（#wyPag4），初始效果为 'slide'，动画时长 800 毫秒。

进阶分：补全按钮点击事件中的 TODO——实现点击按钮切换效果。提示：Swiper 动态换 effect 不能只改参数，需要先销毁旧实例再重建（destroy + new）。第 8 个按钮 slidesPerView 不是 effect，需特殊处理：切换到一个独立的 mousewheel 滚轮切换 Swiper（#myqSw4Wheel），参考官方 demo 100-space-between 配置 spaceBetween: 30、slidesPerView: 3，并开启 mousewheel 滚轮翻页。

⭐ 验证标准：基础分——轮播自动翻页；进阶分——点 cube 变 3D 立方体、点 fade 变淡入淡出、点"多图滚轮"显示三张并排且滚轮可切换
