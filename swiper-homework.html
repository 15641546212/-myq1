提示词工程师让 AI 听懂需求 · 两轮迭代

本次不写代码，写提示词把需求"翻译"给 AI，让它生成 new Swiper('#myqSwiper', {...}) 配置： ① 无循环 ② 3.2 秒自动翻页且手动操作后不停 ③ 圆点分页器可点击 ④ 初始效果 cube。

✍️ 任务一要求

至少迭代 2 轮提示词，保留每轮提示词与 AI 回答；亲自粘进页面验证每项需求。

⭐ 验证标准：无循环、3.2s 自动翻、手滑后不停、圆点可点、初始 cube
第 1 轮
用户提示词：
帮我写一个 Swiper 配置，要求：不循环，3.2秒自动翻页，圆点分页器可以点击跳转，初始效果是 cube。
AI 回答：
好的，以下是满足需求的 Swiper 配置： 
new Swiper('#myqSwiper', {
  loop: false,
  effect: 'cube',
  autoplay: {
    delay: 3200
  },
  pagination: {
    el: '.swiper-pagination',
    clickable: true
  }
});
第 2 轮（修正）
用户提示词：
上一版有问题：用户手动滑动后自动播放会停止。请加上 disableOnInteraction: false， 让手动操作后自动播放不停止。其他要求不变：无循环、3.2秒自动翻页、圆点分页器可点击、初始效果 cube。
AI 回答（修正后）：
已补充 disableOnInteraction: false，修正后的配置如下： 
new Swiper('#myqSwiper', {
  loop: false,
  effect: 'cube',
  autoplay: {
    delay: 3200,
    disableOnInteraction: false
  },
  pagination: {
    el: '.swiper-pagination',
    clickable: true
  }
});

transform 自定义变换

💡 creativeEffect 参数说明（向 AI 追问后的理解）

prev：控制上一张（当前 slide 左侧）的变换——translate: ['-25%', 0, -300] 表示左移 25% 并向 z 轴后退 300px（缩小），rotate: [0, 0, -12] 表示绕 z 轴向左倾斜 12 度。
next：控制下一张（当前 slide 右侧）的变换——translate: ['100%', 0, 0] 表示从右侧 100% 位置进场，rotate: [0, 0, 8] 表示微微向右倾斜 8 度。
百分号基准：transform 里的百分号是相对当前 slide 自身尺寸的。
